# Frozen neural-compiler weights

These are the canonical trained-model files used by the downstream stress-test,
benchmark, and hardware workflows.

## nominal_best_state_dict.pt

Selected nominal compiler weights from the full-Haar nominal training run.

- selected training step: 48,600;
- format: pure PyTorch `state_dict`;
- architecture and physical settings: `configs/nominal.json`;
- frozen validation summary: `results/nominal/final_validation_summary.json`;
- Git blob: `646a8f43955b24a716285f08c8b809febf882d0a`;
- file size: 2,999,065 bytes;
- SHA-256: `8ad39b9ba8b3da1b2bb21957a32bec8fcad169a32efae4a70e2e50f377024188`.

A tensor-by-tensor audit against the original publication export
`best_model_state_dict.pt` found identical keys, shapes, dtypes, and values
(maximum absolute tensor difference 0). The two serialized files need not have
identical byte hashes because PyTorch serialization metadata can differ.

## robust_final_state_dict.pt

Selected risk-aware compiler weights obtained by fine-tuning the nominal model
under the ±5% RF training envelope.

- selected robust validation step: 1,500;
- format: pure PyTorch `state_dict`;
- Git blob: `f1dc4f44f80cb0a96e6c07a06ecfdc6aff257ddb`;
- file size: 2,999,329 bytes;
- SHA-256: `b6369ae86d9a3d7912e47c5d5c645ccb58a3f69ea3a8b24f40a1f069220cc281`.

This robust state dictionary is byte-identical to the model file in the frozen
robust-training export.

Training used only the ±5% RF envelope. The ±7.5%, ±10%, and ±15% RF ranges
are evaluation-only robustness tests.

The repository intentionally keeps one canonical inference state dictionary per
model. Optimizer-state/full-resume checkpoints are generated by the training
notebooks and are not duplicated in the compact public release.
